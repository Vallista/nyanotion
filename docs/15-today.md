# 15 — 오늘 · 일정 · 메모함 · 기록 (Bento 의 생활 기능을 옮긴 것)

Bento(맥)는 블로그 관리만 남기고, 생활 기능(오늘 · 할 일 · 일정 · 루틴 · 회고)은 도란으로 모은다 (`04-history.md`
2026-10-26). 할 일은 체크리스트(`11-checklist.md`), 루틴은 `13-sync.md` §루틴이 이미 맡고 있었고, 여기서 남은
넷을 더한다.

```
 /today     오늘 — 일정 · 할 일(오늘·밀린 것) · 루틴 · 메모함 · 기분/회고를 한 화면에
 /memos     메모함 — 떠오른 것을 적고, 할 일·문서로 옮기거나 끝냈다고 표시
 /journal   기록 — 주간·월간 회고, 지난 하루들(기분·한 줄·하루 회고)
 /          캘린더 — 빈 칸을 누르면 [할 일 | 일정]
```

## 무엇이 누구 것인가

| | 표 | 경계 | 가족에게 |
|---|---|---|---|
| **일정** | `plan_event` | **space** — 캘린더 구독·체크리스트와 같다 | 가족 space 에 적으면 보인다 |
| **메모** | `memo` | **user_id** | 안 보인다 |
| **하루 기록** (기분·에너지·한 줄·하루 회고) | `day_note` (사람 × 날짜) | **user_id** | 안 보인다 |
| **주간·월간 회고** | `review` (사람 × 종류 × 기간) | **user_id** | 안 보인다 |

- 일정의 권한은 space 역할이다(`lib/life-actions.ts` 의 `eventGate`): 보려면 그 space 에 들어갈 수 있어야 하고
  (`viewer.spaceIds`), 적고 고치려면 그 space 에 쓸 수 있어야 한다. 없는 일정·남의 일정·못 고치는 일정은 같은
  말로 거절한다.
- 메모·기분·회고 질의는 전부 `userId` 를 받는다 — 남의 id 를 알아도 읽고 고치고 지울 수 없다 (스모크로 확인).

## 일정 — 할 일이 아닌 것

캘린더에는 셋이 그려진다: 구독한 캘린더의 사본(읽기만), **여기서 적은 일정**, 할 일(체크리스트 항목).
일정은 체크하지 않는다 — 약속·수업·여행처럼 "그 시간에 있는 일"이다.

- 빈 칸을 누르면 창 위에 `[할 일 | 일정]`. 종일·여러 날·시간 일정, 색(구독 캘린더와 같은 6색), 장소, 메모.
- 끝 시각을 안 적으면 한 시간. 같은 날이면 끝이 시작보다 늦어야 한다. 자정을 넘기면 23:59 에서 자른다.
- **끌어서 옮긴다** (데스크탑) — 길이는 그대로. 종일 줄에 놓으면 종일, 종일 일정을 시간 칸에 놓으면 한 시간짜리.
  달 칸에 놓으면 날만 바뀌고 시각은 그대로(할 일은 종일 줄처럼 시각이 빠진다 — 원래 규칙).
- 칸을 그리는 코드는 구독 일정과 적은 일정을 가리지 않는다(`CalEvent = CalendarEventRow & { plan }`).
  고치는 창과 끌기만 `plan` 을 본다.
- 반복 일정은 아직 없다. 반복이 필요한 것은 할 일의 반복이나 구독 캘린더로.
- 규칙은 `packages/shared/src/life.ts` (`normalizePlanEvent` · `movePlanEvent`) 한 곳 — 서버 동작이 화면이 보낸
  값을 믿지 않고 한 번 더 지난다.

## 메모함

- 오늘 화면 오른쪽 위, `/memos`, **⌘K 의 "메모함에 적기"** 세 곳에서 적는다. 폰·브라우저에는 전역 단축키가
  없어서 ⌘K 가 가장 빠른 자리다 (맥의 전역 단축키는 Bento 에 남았다).
- Enter 로 저장, Shift+Enter 로 줄바꿈 (한글 조합 중의 Enter 는 건너뛴다).
- `옮기기` → **할 일로** (첫 줄이 제목, 그 공간의 기본 체크리스트 — `quickAddAction` 과 같은 길) ·
  **내 문서로** (첫 줄이 제목, 나머지가 문단. 새 문서라 `setContent` 를 써도 되는 자리) · 고치기 · 지우기(두 번).
  옮기면 메모는 끝낸 것이 되고 옮긴 곳(`moved_to = todo:<id> | doc:<id>`)을 링크로 남긴다.

## 기분 · 회고

- 하루 한 줄: 기분·에너지 1~5(누르는 즉시 저장, 같은 것을 다시 누르면 지움), 한 줄, 하루 회고. 저녁(18시~)에는
  오늘 화면이 회고 칸을 먼저 연다. 앞날은 못 적는다. 다 비우면 줄이 사라진다.
- 주간·월간 회고는 `/journal` — 이번 주 · 지난주 · 이번 달 · 지난달을 고르고, 쓰는 동안 **그 기간의 하루 기록을
  아래에 펼쳐 둔다**(돌아볼 재료). 빈 글로 저장하면 지운다.
- 주 이름은 `2026-W44` — 이 앱의 주(일요일 시작)를 그 주가 시작한 해의 몇 번째 주로 센다(1월 1일이 든 주가 1주).
  Bento 의 일요일 시작 주 이름과 같은 셈이라 가져온 회고가 같은 주를 가리킨다.
- AI(도우미)로 회고 초안을 쓰는 것은 아직 없다. 넣게 되면 `packages/ai` 를 지나고 **제안으로만** (CLAUDE.md §AI).

## 오늘 화면

일정(적은 것 + 구독 + 시각이 있는 할 일, 시간 순, 지금 줄) · 할 일(밀린 것 먼저, 오늘 것, "오늘 할 일 적기"는
내 기본 체크리스트로) · 오늘 예정인 루틴(체크) · 메모함(위 5개) · 기분/회고. 고치는 길은 전부 원래 화면과 같은
서버 동작이다. 첫 화면(`/`)은 여전히 캘린더다.

## Bento 에서 옮기기

`POST /api/sync/import/bento` (개인 토큰 — `/api/sync/*` 이므로 토큰을 받는 자리다). Bento 는 자기 파일을
**그대로** 보내고(`{version: 1, blocks, moods, summaries, thoughts}`), 모양 바꾸기는
`packages/shared/src/bento-import.ts` (`planBentoImport`) 한 곳에서 한다 — 서버에서 시험할 수 있고 Bento 를 다시
빌드하지 않고도 고칠 수 있게.

| Bento | 도란 | 빼는 것 |
|---|---|---|
| 계획 블록 (`blocks.json`) | 일정 — 토큰 주인의 **개인 space** | 외부 캘린더 사본(gcal·applecal — iCal 로 따로 받는다), 할 일에 매인 블록(할 일은 체크리스트로 온다), 루틴·건강 블록(루틴이 따로 있다), 시간 없는 블록 |
| 생각 (화면 저장소) | 메모 | 줍기·블로그 생각 (Bento 에 남는다) |
| 기분 (`mood.json`, 0~1) | 하루 기록 (1~5) | — |
| 주간·월간 요약 (`summaries.json`, AI) | 회고 (`source = import`, 화면에 "Bento" 표시) | 기간 모양이 틀린 것 |

- **새것만 더한다.** id 는 `bk_<사람>_<Bento id>` 꼴이라 다시 옮겨도 겹치지 않고, 이미 옮긴 일정·메모·회고는
  건드리지 않는다 — 도란에서 고친 것이 덮이지 않는다. 손으로 쓴 회고가 있는 기간은 AI 요약이 들어가지 않는다.
- **하루 기록은 빈칸만 채운다** — 도란에서 적은 기분·회고가 이긴다.
- 블록 종류는 색으로 남는다(미팅 파랑 · 사람 장미 · 글쓰기/독서/배포 청록 · 몰입/제작 보라 · 식사/여가/일상 주황).
  "00:00–00:00"은 종일, "24:00"은 23:59.
- 응답은 더한 수 · 있던 수 · 뺀 까닭별 수. 한 번에 5만 개까지.

## 확인하기

```powershell
pnpm --filter @nyanotion/shared smoke     # 루틴 32개 + 생활 35개 — 일정 모양·옮기기·주 이름·Bento 모양 바꾸기 (DB 없이)
pnpm --filter @nyanotion/db smoke:life    # 31개 — space/사람으로 좁히기, 남의 것은 안 보이고 안 고쳐짐, 옮기기 멱등·빈칸만 채우기
INSPECT_URL=http://localhost:3100 node apps/web/scripts/e2e-life.mjs   # 22개 — 일정 적기·끌기·고치기·지우기, 메모·⌘K·메모→할 일, 기분, 회고 (만든 것은 지운다)
```
