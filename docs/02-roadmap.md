# 로드맵

각 마일스톤은 **끝나면 실제로 써볼 수 있는 상태**가 되도록 잘랐다.
끝낼 때마다 `docs/04-history.md` 에 결정·함정을 적고 다음 항목을 갱신한다.

---

## M0 — 뼈대
- pnpm workspace, `apps/web`(Next.js), `packages/{db,auth,ai,shared}`
- `infra/docker-compose.yml` : postgres(pgvector 포함 이미지) + web
- Drizzle 연결, `0001_auth.sql` 적용
- Better Auth: 이메일+비밀번호 가입/로그인, 세션
- 로그인하면 빈 홈이 뜬다

**완료 기준** — `docker compose up -d` 후 `localhost:3000` 에서 가입·로그인이 되고, 재시작해도 세션이 남는다.

## M1 — 문서와 에디터
- `space` 자동 생성(개인), `document` CRUD
- 사이드바: 문서 트리(중첩), 새 문서, 이름 변경, 드래그로 이동/정렬(fractional index)
- BlockNote 에디터 붙이기, 디바운스 자동 저장
- 저장 시 `text_plain` 파생 생성
- 휴지통(`archived_at`)과 복원

**완료 기준** — 실제로 메모를 쌓아 쓸 수 있다. 여기서부터 이 앱으로 이 앱의 개발 노트를 적는다.

## M2 — 분류와 검색
- 태그 CRUD, 문서에 태그 달기, 태그로 필터
- 즐겨찾기
- Postgres FTS 검색 (`search_tsv`) + 명령 팔레트(Ctrl+K)
- `collection` 1차: 필터 저장 + 리스트/표 뷰

**완료 기준** — 문서가 100개 넘어가도 원하는 걸 3초 안에 찾는다.

## M3 — 계정 · 조직 · 공유
- 조직 생성, 멤버 초대(이메일 링크), 역할 부여
- 조직 space 와 그 문서 트리
- `document_share` : 사용자·조직 대상 공유, 상속 규칙
- `packages/auth/access.ts` 권한 판정 + 그 위의 테스트
- 공개 링크(읽기 전용, 만료·비밀번호 선택)

**완료 기준** — 두 번째 계정으로 로그인해 "내 것은 보이고 남의 것은 안 보인다"가 테스트로 증명된다. 권한 테스트 없이 넘어가지 않는다.

## M4 — 로컬 LLM 기본 기능
- 호스트 Ollama 설치, `packages/ai` 게이트웨이(모델·타임아웃·동시성)
- SSE 스트리밍 `/api/ai/complete`
- 에디터 슬래시 명령: 이어쓰기 / 요약 / 다듬기 / 번역 (선택 블록 컨텍스트)
- **GPU 모드 토글**(`free | gaming`) + 모델 언로드 + UI 표시
- `AI_FALLBACK_BASE_URL` 클라우드 폴백 (선택)

**완료 기준** — 게임을 켠 상태에서 토글을 넘기면 VRAM이 실제로 비워지고, 문서 편집은 전혀 느려지지 않는다.

## M5 — RAG
- `apps/worker` + `ai_job` 큐
- 청킹(`content_hash` 로 변경분만) → 임베딩 → `embedding` upsert
- 하이브리드 검색(FTS + 벡터, RRF)
- 문서 질의 UI: 답변 + 근거 블록으로 점프
- 자동 태그·제목 추천 (수락해야 반영)

**완료 기준** — "지난달에 정리한 배포 절차 뭐였지" 같은 질문에 근거 링크와 함께 답한다. 그리고 **다른 계정의 문서는 절대 근거에 안 나온다**(테스트).

## M6 — 실시간 협업
- `apps/collab` (Hocuspocus) + 인증 훅(access.ts 재사용)
- `content_json → ydoc_state` 1회 마이그레이션, 원본 전환
- 저장 시 `content_json` / `text_plain` 파생 갱신 유지
- 커서 프레즌스, 코멘트, 멘션 알림

**완료 기준** — 두 브라우저에서 같은 문서를 동시에 고쳐도 깨지지 않고, 연결이 끊겼다 붙어도 내용이 살아 있다.

## M7 — 운영
- Cloudflare Tunnel + 도메인
- 일일 `pg_dump` + 첨부파일 백업 스크립트, **복구 리허설 1회**
- Windows 부팅 자동 시작
- 기본 지표(응답시간, 잡 큐 길이, GPU 모드 이력)
- 레이트 리밋, 첨부 용량 제한

**완료 기준** — PC를 재부팅해도 아무 것도 손대지 않고 외부에서 접속된다. 백업에서 복구해 봤다.

---

## 순서를 이렇게 잡은 이유

- **에디터(M1)를 인증 바로 다음에** 둔 건, 이 앱을 개발 노트로 쓰기 시작해야 요구사항이 진짜로 드러나기 때문.
- **조직·권한(M3)을 AI(M4)보다 앞**에 둔 건, 권한 경계가 정해지기 전에 RAG를 만들면 검색 경로를 다시 짜야 하기 때문.
- **협업(M6)을 뒤로** 미룬 건 혼자 쓰는 동안은 가치가 0인데 디버깅 비용은 가장 크기 때문. 대신 M1의 저장 포맷이 미리 대비해 둔다.
