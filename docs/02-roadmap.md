# 로드맵

각 마일스톤은 **끝나면 실제로 써볼 수 있는 상태**가 되도록 잘랐다.
끝낼 때마다 `docs/04-history.md` 에 결정·함정을 적고 이 문서를 갱신한다.

---

## M0 — 뼈대 ✅ (2026-09-25 완료)
- pnpm workspace(`@nyanotion/*`), `apps/web`, `packages/{db,auth,ai,shared}`
- PostgreSQL 17 (Windows 서비스) 에 `nyanotion` DB·역할 — Docker 는 이 PC 에서 안 뜬다 (`docs/03-dev-environment.md`)
- Drizzle 연결, `0001_auth.sql` 적용
- Better Auth: 이메일+비밀번호, 세션, **공개 가입 차단**(`ALLOW_PUBLIC_SIGNUP=false`)
- 로그인하면 빈 캣타워(홈)가 뜬다

**완료 기준** — `localhost:3000` 에서 로그인되고, 서버를 재시작해도 세션이 남는다. 초대 없이는 가입이 안 된다.

확인한 것:
- `pnpm -r typecheck` 통과
- `/login` 200, `/` 는 세션 없으면 307 → `/login`
- 첫 가입은 통과(계정 0개일 때), 두 번째 가입은 **403 “초대를 받은 주소만 가입할 수 있습니다.”**
- 가입과 동시에 개인 space `내 문서` 생성됨
- dev 서버를 껐다 켜도 같은 쿠키로 홈 200 (세션이 DB 에 있다)

## M1 — 문서와 에디터 ✅ (2026-09-25 완료)
- 개인 `space` 자동 생성, `document` CRUD
- 사이드바 문서 트리(중첩), 드래그 이동·정렬(fractional index)
- BlockNote 에디터, 디바운스 자동 저장 (원본은 아직 `content_json`)
- 저장 시 `text_plain` 파생 생성
- 모래상자(휴지통, `archived_at`)와 복원

**완료 기준** — 데스크탑 브라우저에서 메모를 쌓아 쓸 수 있다. **여기서부터 이 앱으로 이 앱의 개발 노트를 적는다.**

확인한 것:
- `pnpm -r typecheck` 통과, `pnpm build` 통과 (첫 로드 JS 108~119 kB)
- 데이터 계층 17개 항목 통과 — `pnpm --filter @nyanotion/db smoke`
  (트리 조립 · 형제 정렬 키 오름차순 · `text_plain` 파생 · 빈 제목 짐작 ·
   부모 바꿔 옮기기 · **자기 하위로 옮기기 거부** · 실패한 이동이 트리를 안 건드림 ·
   모래상자가 하위까지 내려감 · 목록에 부모만 뜸 · 되돌리면 하위까지 살아남)
- `/` `/trash` `/d/[id]` `/login` 전부 200, 없는 문서는 404
- 개인 space 하나 안에서만 동작 — 문서별 권한은 M4

## M2 — 동기화 · 오프라인 · 설치 ★ 이번 설계의 중심
- `apps/collab` (Hocuspocus) + 인증 훅
- `content_json → ydoc_state` 전환, Yjs 를 원본으로
- 클라이언트: `y-indexeddb` 로컬 영속 + `y-websocket` 동기화
- 저장 시 `content_json` · `text_plain` 파생 갱신 유지
- **PWA**: Web App Manifest, Service Worker(앱 셸 캐시 + 오프라인 폴백), 아이콘 🐱
- **Cloudflare Tunnel + 도메인** — HTTPS 없이는 PWA·푸시가 안 된다
- `/install` 설치 안내 페이지 (iOS 홈 화면 추가 스크린샷)
- Persistent Storage 요청 (알림 권한과 함께)

**완료 기준** — **아이폰 홈 화면에서 앱으로 열리고, 비행기 모드에서 메모를 쓰고, 서버를 껐다 켜도 그 메모가 합쳐진다.** 데스크탑과 폰에서 같은 문서를 열어도 안 깨진다.

## M3 — 분류와 검색
- 태그 CRUD, 문서에 달기, 태그 필터
- 츄르(즐겨찾기)
- Postgres FTS(`search_tsv`) + 명령 팔레트(Ctrl+K)
- `collection` 1차: 필터 저장 + 리스트/표 뷰

**완료 기준** — 문서가 100개 넘어도 원하는 걸 3초 안에 찾는다. 폰에서도 검색이 쓸 만하다.

## M4 — 가족 · 공유
- 가족(organization) 생성, **이메일 초대 링크**, 역할 부여
- 가족 space 와 그 문서 트리
- `document_share`: 사용자·가족 대상 공유, 트리 상속
- `packages/auth/access.ts` 권한 판정 **+ 그 위의 테스트**
- 공개 링크(읽기 전용, 만료·비밀번호 선택)

**완료 기준** — 두 번째 계정으로 "내 것은 보이고 남의 것은 안 보인다"가 **테스트로 증명된다.** 권한 테스트 없이 넘어가지 않는다.

## M5 — 로컬 LLM 기본 기능
- 호스트 Ollama, `packages/ai` 게이트웨이(모델·타임아웃·동시성)
- SSE 스트리밍 `/api/ai/complete`
- 슬래시 명령 `/냥이`: 이어쓰기 / 요약 / 다듬기 / 번역 (선택 블록 컨텍스트)
- **GPU 모드 토글**(`free | gaming`) + 모델 언로드 + UI 표시
- `AI_FALLBACK_BASE_URL` 클라우드 폴백 (선택)

**완료 기준** — 게임을 켠 채 토글을 넘기면 VRAM이 실제로 비워지고, 문서 편집·동기화는 전혀 안 느려진다.

## M6 — RAG
- `apps/worker` + `ai_job` 큐
- 청킹(`content_hash` 로 변경분만) → 임베딩 → `embedding` upsert
- 하이브리드 검색(FTS + 벡터, RRF)
- 문서 질의 UI: 답변 + 근거 블록으로 점프
- 자동 태그·제목 추천 (수락해야 반영)

**완료 기준** — "작년에 정리한 김장 레시피 뭐였지" 에 근거 링크와 함께 답한다. 그리고 **다른 가족 구성원의 비공개 문서는 절대 근거에 안 나온다**(테스트).

## M7 — 네이티브 셸 *(조건부 — 필요해질 때만)*
`docs/05-clients.md` §5 의 체크리스트 중 하나라도 실제로 아쉬워지면 착수.
- `apps/shell-desktop` (Electron): 전역 단축키 빠른 메모, 트레이, 자동 시작 — Mac 불필요
- `apps/shell-ios` (Capacitor): 공유 시트, 위젯, Face ID 잠금, 백그라운드 동기화 — **Mac + $99/년 필요**

**완료 기준** — 셸이 UI 코드를 한 줄도 갖지 않는다. 웹 앱만 고쳐도 모든 클라이언트가 갱신된다.

## M8 — 운영 다지기
- 일일 `pg_dump` + 첨부파일 백업 스크립트, **복구 리허설 1회**
- Windows 부팅 자동 시작
- 기본 지표(응답시간, 잡 큐 길이, GPU 모드 이력)
- 첨부 용량 제한, 간단한 레이트 리밋, 감사 로그
- 선택: Cloudflare Access 로 터널 앞단 2차 잠금

**완료 기준** — PC를 재부팅해도 손 안 대고 외부에서 접속된다. 백업에서 복구해 봤다.

---

## 순서를 이렇게 잡은 이유

- **M2(동기화·오프라인·PWA)를 앞으로 당긴 건** 클라이언트가 폰까지 가야 하기 때문. 집 서버는 게임·재부팅으로 자주 꺼지는데, 폰에서 "서버 없음"이 뜨면 이 앱은 쓰이지 않는다. 오프라인 경로가 먼저다.
- **Cloudflare Tunnel 이 M2에 있는 건** PWA·푸시·Persistent Storage 가 전부 HTTPS를 요구하기 때문. 운영 단계로 미룰 수 없다.
- **가족·권한(M4)을 AI(M5~6)보다 앞**에 둔 건, 권한 경계가 정해지기 전에 RAG를 만들면 검색 경로를 다시 짜야 하기 때문.
- **네이티브 셸(M7)을 조건부로 둔 건** Mac과 연 $99가 붙는데, 가족만 쓰는 이상 PWA로 대부분 해결되기 때문. 필요가 증명되기 전엔 안 만든다.
