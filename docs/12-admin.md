# 12 — 어드민: 계정 관리

`/admin` — 이 서버 전체의 계정을 관리한다. **가족 역할(owner/admin)과 다른 축이다.**
가족 admin 은 그 가족에 초대하고 역할을 바꾸고, 서버 어드민은 계정을 만들고 막는다.

## 누가 어드민인가

설정의 **`ADMIN_EMAILS`** (쉼표 구분). 비어 있으면 **그 환경의 첫 계정.**

DB 에 "어드민" 칸을 두지 않았다. 화면에서 어드민을 늘리는 길이 생기면 그 길 하나로 서버 전체가
넘어간다 — 설정 파일은 이 집 컴퓨터에 손댈 수 있는 사람만 바꾼다.

어드민이 아니면 `/admin` 은 **404** 다 (문서 권한과 같은 규칙 — 그런 화면이 있다는 것도 안 알려 준다).
사이드바에도 링크가 없다.

## 할 수 있는 일

| | |
|---|---|
| **초대** | 이메일 하나에 링크 하나. 가족을 고르면 그 가족 초대(`/invite/…`), 안 고르면 **계정만**(`/join/…`, `account_invite`). 14일, **그 주소로만** 가입된다. 메일은 안 간다 — 링크를 복사해 보낸다 |
| **기다리는 초대** | 계정 초대와 모든 가족의 초대. 링크 다시 보기 · 취소 |
| **막기 / 다시 열기** | 막으면 **그 사람의 세션을 전부 지운다** — 들어와 있던 기기도 바로 끊긴다. 새 로그인은 세션 훅이 막는다 ("이 계정은 막혀 있습니다"). 자기 자신과 다른 어드민은 못 막는다 |
| **임시 비밀번호** | 14자, 헷갈리는 글자(0/O, 1/l/I) 없이. **화면에 한 번만** 보여 주고 저장하지 않는다(해시만). 그 사람의 기기는 전부 로그아웃된다. 받은 사람은 `/account` 에서 바꾼다 |
| **가족에 넣기 / 빼기 / 역할** | 이미 계정이 있는 사람을 초대 없이. **마지막 owner 는 내리거나 뺄 수 없다** |

전부 감사 로그(`admin.*`)에 남는다.

## 하지 않는 일

- **계정 지우기.** 그 사람이 쓴 문서와 기록이 남아야 한다. 막기로 충분하다.
- **문서 읽기.** 계정을 관리하는 자리이지 남의 문서를 보는 자리가 아니다 — 개수만 센다.
- **공개 가입.** 계정 초대도 초대다. 가입 훅(`apps/web/src/lib/auth.ts`)은 살아 있는 가족 초대 *또는*
  계정 초대가 있는 주소만 통과시킨다.

## 메일이 없어서

"비밀번호를 잊었어요" 흐름을 만들 수 없다 (메일을 보낼 길이 없다). 그 자리를 **임시 비밀번호**가
대신한다 — 어드민이 만들어 직접 전하고, 받은 사람이 `/account` 에서 바꾼다.

## 확인하기

```powershell
pnpm --filter @nyanotion/db smoke:admin                                # 25개
INSPECT_URL=http://localhost:3100 node apps/web/scripts/e2e-admin.mjs     # 22개 — beta 전용 (시험 계정이 막힌 채 남는다)
```
